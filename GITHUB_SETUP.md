# 🚀 Como Criar Repositório GitHub Pages - ACRDM_Almargem

## 📋 **Passo a Passo Completo**

### **1. Criar Conta GitHub (se ainda tiver)**
- Aceder a https://github.com
- Criar conta gratuita
- Verificar email

### **2. Criar Novo Repositório**
1. **Login** no GitHub
2. **Clicar** em "+" (canto superior direito)
3. **"New repository"**
4. **Preencher:**
   - **Repository name:** `ACRDM_Almargem`
   - **Description:** `Site Oficial da Associação Cultural e Recreativa dos Moradores de Almargem`
   - **Public** ✅
   - **Add a README file** ✅
   - **Add .gitignore** → selecionar "HTML"
   - **Choose a license** → "MIT License"

5. **Clicar** "Create repository"

### **3. Fazer Upload dos Arquivos**
1. **Clicar** "uploading an existing file"
2. **Arrastar** todos os arquivos da pasta:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `pdf-generator.js`
   - `logo.svg`
   - `README.md`
   - `.gitignore`

3. **Commit changes:**
   - "Initial commit - Website ACRDM Almargem"

4. **Clicar** "Commit changes"

### **4. Ativar GitHub Pages**
1. **Settings** (menu lateral)
2. **Pages** (menu esquerdo)
3. **Source:** "Deploy from a branch"
4. **Branch:** "main"
5. **Folder:** "/ (root)"
6. **Clicar** "Save"

### **5. Aguardar Deploy**
- **Aguardar 2-3 minutos**
- **URL será:** `https://[seu-username].github.io/ACRDM_Almargem`

---

## 📧 **Próximo Passo: Web3Forms**

### **1. Criar Conta Web3Forms**
1. **Aceder** a https://web3forms.com/
2. **"Sign Up"**
3. **Email:** usar email da associação
4. **Website URL:** `https://[seu-username].github.io/ACRDM_Almargem`
5. **Verify email**

### **2. Obter Access Key**
1. **Dashboard** Web3Forms
2. **"Create New Form"**
3. **Copiar** "Access Key"

---

## 🔧 **Configurar Email no Site**

Depois de obter a Access Key:

1. **Editar** `script.js`
2. **Substituir** função `enviarFormularioPorEmail`
3. **Colar** Access Key
4. **Testar** formulário

---

## 📱 **URL Final**

- **GitHub Pages:** `https://[seu-username].github.io/ACRDM_Almargem`
- **Web3Forms:** Configurado com esta URL
