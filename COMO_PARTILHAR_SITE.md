# Como Partilhar o Site com Outras Pessoas

## 🌍 **Para que as pessoas encontrem o seu site, precisa de publicar online!**

---

## 📋 **Opções Gratuitas para Publicar o Site:**

### 🥇 **Opção 1 - GitHub Pages (Mais Recomendado)**

**Vantagens:**
- ✅ 100% gratuito
- ✅ Link profissional: `https://[seu-nome].github.io/associacao-almargem`
- ✅ Fácil de atualizar
- ✅ Funciona para sempre

**Passos:**
1. **Vá para:** https://github.com
2. **Crie conta gratuita** (se ainda não tiver)
3. **Clique em "New repository"**
4. **Nome do repositório:** `associacao-almargem`
5. **Clique em "Create repository"**
6. **Clique em "Add file" → "Upload files"**
7. **Arraste os 4 ficheiros:**
   - `index.html`
   - `styles.css` 
   - `script.js`
   - `README.md`
8. **Clique em "Commit changes"**
9. **Vá para Settings → Pages**
10. **Selecione "Deploy from a branch"**
11. **Escolha "main" e "/root"**
12. **Clique em "Save"**
13. **Aguarde 2-3 minutos**
14. **Seu site estará em:** `https://[seu-usuario].github.io/associacao-almargem`

---

### 🥈 **Opção 2 - Netlify**

**Vantagens:**
- ✅ Super fácil de usar
- ✅ Link curto e bonito
- ✅ Funciona imediatamente

**Passos:**
1. **Vá para:** https://netlify.com
2. **Clique em "Sign up"** (gratuito)
3. **Arraste a pasta `associacao-almargem`** para a página
4. **Pronto! Site publicado com link aleatório gratuito**

---

### 🥉 **Opção 3 - Vercel**

**Vantagens:**
- ✅ Muito profissional
- ✅ Rápido e moderno

**Passos:**
1. **Vá para:** https://vercel.com
2. **Clique em "Sign up"** (gratuito)
3. **Clique em "New Project"**
4. **Faça upload dos ficheiros**
5. **Site publicado instantaneamente**

## 🔄 **Como Atualizar o Site:**

### **Se usar GitHub Pages:**
1. **Faça alterações nos ficheiros**
2. **Vá ao seu repositório GitHub**
3. **Clique em "Add file" → "Upload files"**
4. **Substitua os ficheiros alterados**
5. **Site atualiza automaticamente em 1-2 minutos**

---

## 📊 **Dados do Site Online:**

### **Importante Saber:**
- ❌ **Dados não partilhados:** Cada pessoa vê os seus próprios dados
- ❌ **Não há base de dados central**
- ✅ **Cada utilizador guarda os dados no seu navegador**
- ✅ **Funciona como cópia individual para cada pessoa**

### **Solução para Dados Compartilhados:**
Se precisar que todos vejam os mesmos dados:
1. **Use o site para mostrar informações**
2. **Para dados importantes, use Google Sheets gratuito**
3. **Coloque link do Google Sheets no seu site**

---
