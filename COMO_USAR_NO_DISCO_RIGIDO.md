# Como Guardar o Site no Disco Rígido - Guia Passo a Passo

## 🎯 O que precisa fazer:

O site já está criado e guardado no seu computador! Só precisa de saber como usá-lo.

## 📍 Onde está o site:

**Localização exata:** `C:\Users\FlavioMelo\CascadeProjects\associacao-almargem\`

## 📂 Passo 1 - Encontrar os ficheiros

1. **Abra o Explorador de Ficheiros** (ícone da pasta amarela)
2. **Clique em "Este PC"** ou "Computador"
3. **Navegue até:** `C:\Users\FlavioMelo\CascadeProjects\associacao-almargem\`
4. **Verá 4 ficheiros:**
   - `index.html` (página principal)
   - `styles.css` (cores e design)
   - `script.js` (funcionalidades)
   - `README.md` (instruções)

## 🖱️ Passo 2 - Abrir o site

1. **Dê duplo clique no ficheiro `index.html`**
2. **O site abrirá automaticamente no seu navegador** (Chrome, Firefox, Edge)
3. **Pronto! O site está a funcionar** no seu computador

## 💾 Como guardar os dados que inserir

Os dados (relatórios, sócios, reservas, etc.) são guardados automaticamente no navegador.

### Para fazer backup dos dados:

1. **Abra o site** (duplo clique em `index.html`)
2. **Pressione a tecla F12** no teclado
3. **Aparecerá uma janela à direita** - vá para o separador "Console"
4. **Escreva:** `exportData()` 
5. **Pressione Enter**
6. **Um ficheiro será descarregado** automaticamente
7. **Guarde este ficheiro** - contém todos os seus dados

## 🔄 Como restaurar dados do backup

Se precisar de restaurar os dados:

1. **Abra o site** (duplo clique em `index.html`)
2. **Pressione F12** e vá para "Console"
3. **Escreva:** `clearData()` e pressione Enter
4. **Recarregue a página** (F5)
5. **Adicione novamente os dados manualmente**

## 📋 Para copiar para outro disco rígido

### Método 1 - Copiar e Colar (Mais fácil)

1. **Abra a pasta:** `C:\Users\FlavioMelo\CascadeProjects\associacao-almargem\`
2. **Selecione todos os ficheiros** (Ctrl + A)
3. **Clique com o botão direito** e escolha "Copiar"
4. **Vá para o disco rígido** onde quer guardar
5. **Crie uma nova pasta** chamada "Site Associação"
6. **Dentro da pasta, clique com botão direito** e escolha "Colar"
7. **Pronto! O site está copiado**

### Método 2 - Pen Drive

1. **Ligue uma pen USB** ao computador
2. **Siga os passos do Método 1** mas cole na pen drive
3. **Pode usar noutro computador** da mesma forma

## 📱 Como usar no dia a dia

1. **Crie um atalho no ambiente de trabalho:**
   - Clique com botão direito em `index.html`
   - Escolha "Enviar para" → "Ambiente de trabalho"

2. **Use sempre o mesmo navegador** para não perder dados

3. **Faça backup regularmente** (uma vez por mês)

## 🆘 Se algo não funcionar

### Problema: "O site não abre"
- **Solução:** Certifique-se que abre o ficheiro `index.html`

### Problema: "Perdi todos os dados"
- **Solução:** Se não fez backup, precisa de inserir tudo novamente

### Problema: "As imagens não aparecem"
- **Solução:** As imagens ficam guardadas no navegador, não no disco
