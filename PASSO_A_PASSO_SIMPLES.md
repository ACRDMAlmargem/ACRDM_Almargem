# 🎯 PASSO A PASSO SIMPLES - Como Começar a Usar o Site

## 📋 **O que precisa fazer AGORA:**

---

## 🖥️ **PASSO 1 - Abrir o Site no seu Computador**

1. **Pressione a tecla Windows + E** (abre Explorador de Ficheiros)
2. **Na barra de endereço (topo), cole:** `C:\Users\FlavioMelo\CascadeProjects\associacao-almargem`
3. **Pressione Enter**
4. **Procure o ficheiro `index.html`**
5. **Dê duplo clique em `index.html`**
6. **O site abrirá no seu navegador** ✅

---

## 📱 **PASSO 2 - Testar os Separadores**

No site que abriu, clique em cada separador:

1. **Contactos** - Verifique se mostra o email e Facebook
2. **Relatórios** - Tente adicionar um relatório de teste
3. **Publicações** - Tente fazer uma publicação
4. **Sócios** - Veja a lista de exemplo
5. **Reservas** - Faça uma reserva de teste

---

## 💾 **PASSO 3 - Fazer Backup dos Dados (Importante!)**

1. **Com o site aberto, pressione F12**
2. **Aparece uma janela à direita - clique em "Console"**
3. **Escreva:** `exportData()`
4. **Pressione Enter**
5. **Um ficheiro descarrega automaticamente**
6. **Guarde este ficheiro numa pasta segura**

---

## 🌍 **PASSO 4 - Publicar Online (Para Partilhar com Outros)**

### **Opção A - Netlify (Mais Fácil)**

1. **Vá para:** https://netlify.com
2. **Clique em "Sign up"** (crie conta gratuita)
3. **Arraste a pasta `associacao-almargem`** para a página
4. **Pronto! Site publicado com link para partilhar**

### **Opção B - GitHub Pages (Mais Profissional)**

1. **Vá para:** https://github.com
2. **Crie conta gratuita**
3. **Crie repositório chamado `associacao-almargem`**
4. **Faça upload dos 4 ficheiros:**
   - index.html
   - styles.css
   - script.js
   - README.md
5. **Vá para Settings → Pages**
6. **Ative Pages**
7. **Seu link será:** `https://[seu-nome].github.io/associacao-almargem`

---

## 📢 **PASSO 5 - Partilhar o Site**

Depois de publicado, partilhe o link:

- **WhatsApp:** Envie para os sócios
- **Facebook:** Publique na página "Almargem.2026"
- **Email:** Inclua nas comunicações
